# Swiggy-Inspired Food Delivery Website

A Swiggy-inspired food delivery website built using **HTML5 and CSS3**. The complete project, including the CSS styling, is contained in a single `index.html` file.

## 🚀 Features

* Navigation bar
* Search section
* Food category cards
* Restaurant and food sections
* Dineout section
* Location-based sections
* Responsive layout
* Structured footer
* Clean and visually appealing UI

## 🛠️ Technologies Used

* HTML5
* CSS3

## 📁 Project Structure

```text
Swiggy/
└── index.html
```

## 🎯 Project Objective

The project was created to practice building a real-world food delivery website interface using HTML and CSS. It focuses on webpage structure, layout, Flexbox, spacing, positioning, typography, images, and responsive design.

## 💡 What I Learned

* Creating structured webpages using HTML
* Styling webpages using CSS
* Using Flexbox for layouts
* Creating cards and different website sections
* Working with images
* Improving spacing and alignment
* Building responsive and user-friendly interfaces
